# Code of conduct

Gatewright's community follows a simple standard: **be respectful, be constructive, assume good intent.**

- Welcome people of every background and experience level. Beginners' questions are good questions.
- Critique code and ideas, never people.
- No harassment, insults, discrimination, sexual content or personal attacks, in any project space
  (issues, pull requests, discussions, chat).
- Respect people's time: give enough context, and accept "no" on scope decisions gracefully.

Maintainers may edit or remove content, and temporarily or permanently block people who don't follow
this. Report problems privately to the maintainers (see the repository profile). Reports are handled
confidentially.

For a fuller reference, this project aligns with the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
